# Pokedex Java

Projeto desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento Back-end em Java através do consumo da PokéAPI.

## Sobre o projeto

A aplicação permite consultar Pokémon utilizando a PokéAPI, convertendo respostas JSON em objetos Java para exibição e manipulação dos dados.

O projeto foi criado como parte dos meus estudos em Java e Spring Boot, com foco na consolidação dos conceitos de APIs REST, Programação Orientada a Objetos e modelagem de dados.

⚠️ Projeto em desenvolvimento. Novas funcionalidades e melhorias serão adicionadas conforme avanço nos estudos de Java e Spring Boot.

## Tecnologias utilizadas

- Java
- HttpClient
- Gson
- Records
- Collections
- PokéAPI

## Funcionalidades atuais

- Consulta de Pokémon pelo nome
- Consumo de API REST
- Conversão de JSON para objetos Java
- Exibição de informações do Pokémon
- Criação de equipe utilizando listas
- Tratamento básico de exceções

## Conceitos praticados

- Requisições HTTP (GET)
- JSON
- Desserialização com Gson
- Records
- Encapsulamento
- Collections
- Laços de repetição
- Tratamento de erros
- Programação Orientada a Objetos
